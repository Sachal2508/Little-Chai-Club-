# Little Chai Club — UI Design Handoff

This package is intended for the UI design team to review and adapt the visible website experience.

## Included
- Main landing page (`index.html`)
- Privacy Notice page (`privacy.html`)
- Branded not-found page (`404.html`)
- HTML, CSS, fonts, images, icons, and the social-sharing preview image
- Character-picker interaction in `js/main.js`

## Intentionally excluded
- API/serverless signup handler and all backend integration
- Deployment and hosting configuration
- Internal decision notes, launch checklists, and deployment instructions
- Repository history and environment configuration

## Important
The early-access forms are visual placeholders in this package. They do not collect or transmit email addresses. The UI team can freely change the markup, layout, styles, and assets; this package does not impose a framework or build system.

## Preview locally
Open `index.html` in a browser. For best results, use a simple local static server so paths behave consistently. No build step or package installation is required.
